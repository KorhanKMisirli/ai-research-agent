# AI Research Agent - Claude Code Instructions

## Project Goal
Build a reliable AI Research Agent using Python and Claude.

## Development Rules
- Read AGENTS.md before making changes.
- Explain technical concepts in simple Turkish.
- Write code and documentation in English.
- Work in small, testable steps.
- Explain the purpose of each file.
- Never invent research sources or results.
- Never hardcode API keys or credentials.
- Ask for approval before installing packages, deleting files, or accessing external services.
- Add tests when implementing new functionality.

## Workflow
1. Explain the next development step.
2. Make only the agreed changes.
3. Run relevant tests when available.
4. Report what worked and what failed.
5. Wait for approval before proceeding.
